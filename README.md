# SecureCorp Security Assessment Engagement

A four-week security assessment capstone project against an isolated lab environment (Kali Linux attacker, Metasploitable2/DVWA target, centralized logging on a Host Only virtual network).

## Contents
- **SecureCorp-Full-Submission.pdf** — complete engagement report (all weeks, reflection, research log, and slides combined)
- **Week1-Report.pdf** — Lab build, network isolation, asset/CIA/risk analysis, centralized logging
- **Week2-Report.pdf** — Red team assessment: recon, a real CVE exploited to root shell, DVWA web attacks, credential brute-forcing, CVSS v3.1 scoring
- **Week3-Report.pdf** — Blue team investigation: manual log analysis, detection coverage, and a full incident report on an unauthorized intrusion found during the engagement
- **Week4-Report.pdf** — Recommendations, executive summary, and limitations
- **Week4-Reflection.pdf** — Personal reflection on the engagement
- **Week4-Slide-Deck.pptx** — Final client debrief presentation
- **Research-Log.pdf** — Record of troubleshooting and research performed during the engagement

## Tools Used
UTM, Kali Linux, Metasploitable2, DVWA, Nmap, Metasploit, Hydra, rsyslog

## Note
This was conducted entirely within an isolated lab network (Host Only mode) with no route to any external or production system.
